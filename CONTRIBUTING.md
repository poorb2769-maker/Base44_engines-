# Contributing to Base44 Engine\n\n## Welcome! 👋\n\nBase44 is an open-source game engine and we'd love your contributions!\n\n## How to Contribute\n\n### 1. Report Bugs\n\n- Check [existing issues](https://github.com/poorb2769-maker/Base44_engines-/issues)\n- Create detailed bug reports with:\n  - Reproduction steps\n  - Expected vs actual behavior\n  - System info (OS, browser, GPU)\n  - Code snippet if possible\n\n### 2. Suggest Features\n\n- Use [Discussions](https://github.com/poorb2769-maker/Base44_engines-/discussions)\n- Describe the feature\n- Explain use cases\n- Provide examples\n\n### 3. Submit Code\n\n#### Setup Development Environment\n\n```bash\n# Fork the repository\ngit clone https://github.com/YOUR_USERNAME/Base44_engines-.git\ncd Base44_engines-\n\n# Create development branch\ngit checkout -b feature/my-feature\n\n# Install dependencies\nnpm install\n\n# Start development\nnpm run dev\n```\n\n#### Code Style\n\n```typescript\n// Use TypeScript\n// Follow naming conventions\n// Add JSDoc comments\n// Keep functions small and focused\n\n/**\n * Brief description\n * @param param Description\n * @returns Description\n */\npublic myMethod(param: string): void {\n  // Implementation\n}\n```\n\n#### Testing\n\n```bash\n# Run tests\nnpm test\n\n# Run linting\nnpm run lint\n\n# Type checking\nnpm run type-check\n```\n\n#### Commit Messages\n\n```\nchore: update dependencies\nfeature: add new particle effect\nfix: resolve physics collision issue\ndocs: improve API documentation\ntest: add unit tests for AI system\n```\n\n### 4. Improve Documentation\n\n- Fix typos and unclear sections\n- Add code examples\n- Create tutorials\n- Improve API documentation\n\n### 5. Create Sample Projects\n\n- Build games showcasing engine features\n- Add to `/examples/` directory\n- Include documentation\n- Make source code available\n\n## Pull Request Process\n\n1. **Fork** the repository\n2. **Create** a feature branch (`git checkout -b feature/amazing-feature`)\n3. **Commit** your changes (`git commit -m 'Add amazing feature'`)\n4. **Push** to the branch (`git push origin feature/amazing-feature`)\n5. **Open** a Pull Request\n\n### PR Checklist\n\n- [ ] Code follows style guide\n- [ ] Added/updated tests\n- [ ] Updated documentation\n- [ ] Added examples if needed\n- [ ] No breaking changes (or documented)\n- [ ] Tested on multiple browsers\n- [ ] Performance considered\n\n## Development Guidelines\n\n### Architecture Principles\n\n1. **Modularity**: Systems should be independent\n2. **Simplicity**: Keep APIs intuitive\n3. **Performance**: Optimize hot paths\n4. **Compatibility**: Support modern browsers\n5. **Documentation**: Every public API is documented\n\n### File Structure\n\n```\nsrc/engine/\n├── core/              # Base classes\n├── physics/           # Physics system\n├── input/             # Input handling\n├── animation/         # Animation system\n├── audio/             # Audio system\n├── rendering/         # Rendering and effects\n├── editor/            # Editor tools\n├── gameplay/          # Game mechanics\n├── optimization/      # Performance\n├── networking/        # Multiplayer\n└── index.ts           # Exports\n```\n\n### Naming Conventions\n\n- **Classes**: `PascalCase` (e.g., `CharacterController`)\n- **Methods**: `camelCase` (e.g., `setVelocity`)\n- **Constants**: `UPPER_SNAKE_CASE` (e.g., `MAX_HEALTH`)\n- **Interfaces**: `PascalCase` with `I` prefix (e.g., `IRigidbodyConfig`)\n- **Files**: `kebab-case` (e.g., `character-controller.ts`)\n\n### Performance\n\n- Minimize allocations in hot loops\n- Use object pooling when appropriate\n- Profile before optimizing\n- Document performance implications\n\n## Areas We Need Help\n\n### High Priority\n- [ ] WebGL renderer improvements\n- [ ] Physics engine optimization\n- [ ] Mobile performance\n- [ ] Networking stability\n\n### Medium Priority\n- [ ] Additional shader effects\n- [ ] More animation tools\n- [ ] Editor UI improvements\n- [ ] Sample projects\n\n### Nice to Have\n- [ ] Visual scripting system\n- [ ] AI behavior tree UI\n- [ ] Level editor\n- [ ] Asset store integration\n\n## Questions?\n\n- 💬 [Ask on Discussions](https://github.com/poorb2769-maker/Base44_engines-/discussions)\n- 📧 Email: support@base44.dev\n- 🎮 [Join Discord](https://discord.gg/base44)\n\n## Code of Conduct\n\nWe are committed to providing a welcoming and inclusive environment for all contributors. Please read our [Code of Conduct](./CODE_OF_CONDUCT.md).\n\n## License\n\nBy contributing, you agree that your contributions will be licensed under the MIT License.\n\n---\n\n**Thank you for contributing to Base44! 🎉**\n"
